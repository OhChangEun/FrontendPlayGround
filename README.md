# FrontendPlayGround
학습 기록용 레포지토리

## 구조
- `src/exercises/NN-이름.tsx` — 실습 코드. `src/App.tsx`에서 하나를 import해서 띄움.
- `docs/exercises/NN-이름.md` — 실습 명세, 확인 항목, 배운 것 / 헷갈렸던 것.
- 명세를 왼쪽, 코드를 오른쪽에 두고 푼다.
